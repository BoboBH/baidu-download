快速部署:
---------
1. 解压 baidu-download-v1.2.0-exe.zip
2. 进入 dist/ 目录: cd dist
3. 配置环境: cp .env.example .env (然后编辑.env文件)
4. 初始化数据库: mysql -u user -p database < middle/db_init.sql
5. 运行程序: baidu-download.exe --help

v1.2.0 新功能:
-------------
✨ 分离式架构:
   --receive-messages    专职接收飞书消息模式
   --process-pending     专职处理待处理消息模式
   保留原有功能: --auto、--link/--code/--folder 手动模式

📊 消息管理:
   消息状态管理: pending, processing, success, failed, critical_error
   MD5哈希去重机制
   双层次钉钉通知系统

🔧 修复:
   修复 ExecutionSummary 参数名大小写不匹配问题
   优化钉钉通知逻辑，简化通知内容

生产环境部署建议:
------------------
# Windows定时任务设置
# 每小时接收消息
schtasks /create /tn "百度下载-接收消息" /tr "baidu-download.exe --receive-messages" /sc hourly

# 每2小时处理消息
schtasks /create /tn "百度下载-处理消息" /tr "baidu-download.exe --process-pending" /sc hourly /mo 2
