============================================================
百度网盘PDF文件自动传输系统 - Windows部署包 v1.1.5
============================================================

文件说明:
  baidu-download.exe  - 主程序可执行文件 (单文件模式)
  .env.example        - 配置文件模板
  middle/             - 数据库脚本目录
    db_init.sql      - 数据库初始化脚本

快速开始:
1. 复制 .env.example 为 .env
2. 编辑 .env 文件，配置您的环境参数
3. 确保MySQL数据库已安装并运行
4. 运行数据库初始化: mysql -u root -p < middle\db_init.sql
5. 测试运行: baidu-download.exe --help

使用模式:

  手动模式:
    baidu-download.exe --link "分享链接" --code "提取码" --folder "目录名"

  自动模式:
    baidu-download.exe --auto

  配置测试:
    baidu-download.exe --dry-run

  详细日志:
    baidu-download.exe --auto --verbose

系统要求:
  - Windows 10/11 或 Windows Server 2016+
  - 网络连接 (访问百度网盘API、SFTP服务器)
  - MySQL数据库 (本地或远程)
  - 飞书账号 (自动模式需要)

配置要点:
  1. 百度网盘配置: BAIDUPCS_GO_PATH必须指向有效的BaiduPCS-Go.exe
  2. SFTP配置: 确保服务器地址、端口、凭据正确
  3. 数据库配置: 确保MySQL服务运行，数据库权限正确
  4. 飞书配置: 自动模式需要配置飞书应用凭证

常见问题:
  1. 如果可执行文件无法运行，检查.env文件是否存在
  2. 如果数据库连接失败，验证MySQL服务和配置
  3. 如果SFTP上传失败，检查网络连接和服务器权限
  4. 如果飞书集成有问题，验证应用凭证和网络连接

Windows任务计划程序设置:
  1. 打开"任务计划程序" (taskschd.msc)
  2. 创建基本任务，设置触发器 (如每天特定时间)
  3. 操作: 启动程序 "baidu-download.exe"，参数 "--auto"
  4. 设置"不管用户是否登录都要运行"和"使用最高权限运行"

技术支持:
  - 查看日志文件: ./logs/transfer.log
  - 启用详细日志: 添加 --verbose 参数
  - 配置测试: 使用 --dry-run 参数
