## 已知问题和限制

### 功能限制
1. 仅支持公开访问的微信公众号文章
2. PDF文件大小限制为200MB
3. 需要稳定的网络环境

### 环境要求
1. Python 3.8+
2. Playwright浏览器自动化
3. 稳定的SFTP连接
4. 钉钉API访问权限

### 性能考虑
1. 单篇文章处理时间: 30-300秒
2. 建议间隔发送多个文章请求
3. 临时存储空间需求: 5GB+
