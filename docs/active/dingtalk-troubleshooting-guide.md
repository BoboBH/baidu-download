# 钉钉反馈消息问题排查指南

## 问题：为什么没有收到反馈消息？

### 已确认的信息
- ✅ 代码功能正常
- ✅ Webhook URL 已配置
- ✅ 消息标题包含 "feedback:" 关键词
- ✅ 测试消息发送成功

### 需要检查的地方

#### 1. 检查钉钉群中的机器人
在你的钉钉群中：
1. 点击群设置 → 智能群助手
2. 找到用于发送消息的机器人
3. 查看机器人的安全设置

**关键问题**：
- 机器人是否设置了关键词验证？
- 如果设置了，关键词是什么？
- 是不是 "feedback" 这个关键词？

#### 2. 确认两个不同的机器人
**你需要两个不同的钉钉机器人**：

**机器人 A (接收消息)**：
- 类型：Stream API 机器人
- 凭证：DINGTALK_APP_KEY + DINGTALK_APP_SECRET
- 功能：接收群里的 @消息

**机器人 B (发送消息)**：
- 类型：Webhook 机器人  
- 凭证：DINGTALK_WEBHOOK
- 功能：向群里发送反馈消息

#### 3. 解决方案

**方案 1：修改机器人关键词设置**
1. 在钉钉群中找到 Webhook 机器人
2. 进入机器人设置 → 安全设置
3. 添加关键词：`feedback`
4. 保存设置

**方案 2：关闭关键词验证**
1. 在机器人设置中选择安全设置
2. 关闭关键词验证
3. 改用其他验证方式（如IP地址限制）

**方案 3：修改代码中的关键词**
如果你的机器人关键词不是 "feedback"，需要修改代码：
```python
# 在 src/feishu/dingtalk_group_client.py 中
if is_valid:
    title = "你的关键词: 收到有效百度网盘链接"  # 修改这里
else:
    title = "你的关键词: 消息格式无效"     # 修改这里
```

### 快速验证方法

1. **确认测试消息是否收到**
   - 运行 `python test_current_config.py`

2. **检查群中的机器人列表**
   - 确认群中有几个机器人
   - 确认 Webhook URL 对应的机器人确实在这个群里

3. **查看机器人设置**
   - 截图机器人的安全设置
   - 确认关键词配置

## 技术细节

### 消息发送流程
```
用户发送 @消息 
  ↓
机器人 A 接收消息 (Stream API)
  ↓
解析并处理消息
  ↓
机器人 B 发送反馈 (Webhook API)
  ↓
群里收到反馈消息
```

### 可能的失败点
1. 机器人 B 不在群里 → Webhook 发送成功但群里看不到
2. 关键词验证失败 → 钉钉拒绝发送，返回错误 310000
3. Webhook URL 过期或错误 → 发送失败
4. 网络问题 → 发送超时或失败
