## 🚀 部署指南

### 快速部署步骤

1. **解压文件**
   ```bash
   unzip baidu-download-v1.3.3.zip
   cd release_package
   ```

2. **配置环境**
   ```bash
   # 复制配置文件模板
   cp .env.example .env
   
   # 编辑配置文件（必需配置）
   # - SFTP服务器信息
   # - MySQL数据库信息  
   # - 微信功能配置（可选）
   ```

3. **初始化数据库**
   ```bash
   mysql -u root -p test < database/wxchat_tables.sql
   ```

4. **运行程序**
   ```bash
   # 处理微信文章（自动同步账号 + 生成PDF）
   baidu-download.exe --wxchat --wxchat-days 7
   
   # 仅同步账号
   baidu-download.exe --wxchat-sync-accounts
   
   # 手动模式
   baidu-download.exe --link "百度网盘链接" --code "提取码" --folder "目标目录"
   ```
